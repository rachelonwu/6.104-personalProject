
# SnapBack — User Journey

## User and Goal

**User:** A college student who frequently takes screenshots of events, deadlines, and other information they want to revisit.

**Goal:** Turn a screenshot of an upcoming career fair into an actionable task with a reminder, rather than leaving it forgotten in their photo library.

## Scenario

The student receives an announcement about an upcoming career fair. They take a screenshot because they want to attend, but they are busy and don't have time to organize the information immediately.

### 1. Upload a Screenshot

The student logs into SnapBack and selects the career fair screenshot from their device. A preview appears so they can verify that they selected the correct image. They then upload it to SnapBack.

### 2. Generate an AI Suggestion

The student clicks **Generate AI Suggestion**. SnapBack analyzes the screenshot and suggests an intended action, such as "Attend the career fair."

If the screenshot includes a recognizable date or time, SnapBack also suggests that information for a reminder.

Alternatively, the student can skip AI generation and enter their intended action manually.

### 3. Review and Edit the Action

The student reviews the suggestion and changes it to "Prepare for and attend the career fair."

Because the intended action is directly editable, the student does not need to go through a separate correction step.

### 4. Set a Reminder

The student reviews the suggested reminder and can choose between:

- **Date only:** Set a reminder for a selected calendar date.
- **Date and time:** Set a reminder for a specific date and time.
- **No reminder:** Create the task without scheduling a notification.

The student can adjust the suggested date and time before saving.

### 5. Create the Task

The student clicks **Create Task**.

SnapBack saves the intended action as a task, along with the optional reminder and its connection to the original screenshot.

### 6. Manage the Task

The task appears in **My Tasks**, where the student can:

- Mark it as complete.
- Edit the task description.
- Add, change, or remove a reminder.
- View the original screenshot.
- Delete the task.

### 7. Receive a Notification

At the scheduled reminder time, SnapBack sends a browser notification if the student has granted notification permission and the application is open.

The notification reminds the student to prepare for the career fair.

## Outcome

The student successfully turns a screenshot into an actionable task with a reminder. Instead of relying on memory or searching through their photo library later, they can return to SnapBack to see what they intended to do.

SnapBack reduces the effort of organizing saved information by connecting screenshots to concrete actions.

## Current Limitation

Browser notifications require SnapBack to be open. The application does not currently support push notifications when it is closed.
